# Teacher revision boundary

These files are validated declarations, not proof that a model was downloaded or executed. The first VI→EN audit chain has immutable revisions and decoding contracts, but no teacher is `approved` until real audit evidence passes. Inference refuses unpinned revisions.

Noncommercial or output-restricted teachers remain marked `research_only`. NLLB is restricted to noncommercial research, and SeamlessM4T remains on hold for a separate terms/output review. Labels stay segregated with source, teacher, revision, license, generation hash, timestamp, and later filtering decisions. Bulk predictions belong in private ignored SQLite/data storage, never Git and never the gold evaluation set.
