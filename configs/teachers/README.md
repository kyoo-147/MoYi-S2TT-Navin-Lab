# Teacher candidate boundary

These files are validated declarations, not proof that a model was downloaded or executed. No teacher is approved yet: every candidate still has `revision: null`, and inference refuses unpinned revisions.

Noncommercial or output-restricted teachers remain marked `research_only`. Their labels must stay segregated with source, teacher, revision, license, generation hash, timestamp, and later filtering decisions. Bulk predictions belong in ignored SQLite/data storage, never Git.
